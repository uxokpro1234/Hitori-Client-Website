FAQ

What is Hitori Client?

Hitori Client is a utility mod designed for 2b2t and other anarchy Minecraft servers.

It provides various utility and quality-of-life features while remaining useful outside of anarchy servers as well.

What does the interface look like?

The interface is designed to be simple and easy to use.

Is Hitori Client only for anarchy servers?

No. While Hitori Client was made with anarchy servers in mind, the client can also be used beyond them.

Why choose Hitori Client?

Hitori Client provides many of the same types of functions found in other clients while maintaining a low price.

We continue to support anarchy servers and improve the client.
