## About

This repository contains the **Hitori Client website**.

It was originally created to be the main website for **Hitori Client** back when the client was still being developed and sold. The website was meant to be the place where people could learn about the client, look through its features, find the FAQ, watch the promotional video, contact the developers, and eventually buy the client.

Today, Hitori Client is **discontinued**.

The website is no longer an active commercial project. I'm keeping this repository around as an archive of what the project looked like and, honestly, as a small piece of my own history on the internet.

This isn't meant to be some polished modern project or an attempt to bring Hitori Client back.

It's just here because it existed.

---

# A Little History

Hitori Client was a utility mod made for **2b2t and other anarchy Minecraft servers**.

At the time, the idea was to make a relatively low-price client with various utilities and features that could be used on anarchy servers, while still being useful outside of them.

The website was created around that idea.

It had a home page, features page, FAQ, information about the developers and testers, a video, a purchase link, and a Discord server.

Looking at the code now is honestly kind of funny.

A lot of this website was written with very old HTML and CSS techniques. There are fixed-width containers everywhere, `<br>` tags being used for spacing, questionable margins, duplicated CSS rules, and probably more sins against web development than I want to count.

But that's also part of why I wanted to preserve it.

This is what the project looked like back then.

# What Was Hitori Client?

Hitori Client was intended to be a **utility mod for Minecraft**, primarily aimed at anarchy servers such as 2b2t.

The original website described it as a mod rather than a traditional "cheat client" or "hacked client", comparing it more to mods such as OptiFine or Impact.

The client included various utilities and features intended for anarchy gameplay.

One of the features mentioned on the old website was **CrystalAura**, which was intended to work across many anarchy servers.

The project was also advertised as being relatively inexpensive compared with other clients at the time.

# What Happened?😭

Eventually, Hitori Client was discontinued.

At some point, the client was also cracked by **catynDMG and his team**, at least as I remember it.

After that, things basically came to an end.

Igrik2.0 eventually quit making cheats and, as far as I know, pretty much left the internet altogether.

I haven't really heard from him since around **summer 2022**.

Nothing.

We used to be cool.

Then he just disappeared.

I don't know what happened to him after that, and I'm not going to make up a story about it.

That's simply how I remember things ending.

# Why Keep This?

Because old internet projects disappear ridiculously easily.

Websites go offline.

Domains expire.

Discord servers disappear.

Downloads stop working.

People delete accounts.

Projects get abandoned.

And eventually, something that used to be a real part of someone's life becomes a dead link.

This repository is my way of keeping one of those things around.

Hitori Client wasn't some massive company or legendary software project.

It was a relatively small Minecraft client.

But I was there.

I remember working around the project, seeing the website, talking to people involved, and watching the whole thing exist and eventually disappear.

So now it's archived here.

# Anarchy Minecraft

Hitori Client came from the old Minecraft anarchy scene, where clients, utility mods, exploits, dupes, bases, PvP, and server history were a huge part of the community.

2b2t in particular had an enormous ecosystem around it.

Hitori was one small project within that much larger scene.

The project is gone now, but the website remains as a snapshot of what that little project looked like.
